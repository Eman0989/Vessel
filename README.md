# VESSEL

VESSEL is a distributed WebAssembly execution fabric for securely running portable workloads across heterogeneous compute.

## Goals

- WebAssembly Component execution
- capability-based workload isolation
- distributed workload scheduling
- worker health monitoring
- automatic failure recovery
- content-addressed deployments
- rolling and canary releases
- autoscaling
- observability
- real-time cluster operations

## Status

Early development.
